# SCN-LIB-001 需求分析（SA）

## 文件資訊

- 需求文件 ID：REQ-LIB-001
- 來源情境：SCN-LIB-001
- UI 設計來源：docs/figma/library-mini-admin-console/README.md；Figma Make URL：https://www.figma.com/make/3ilP5JnPlkgXomqo70MsDW/Library-Mini-Admin-Console?p=f&fullscreen=1

## 1) 需求摘要

- 情境目標：讓共享書櫃管理員建立館藏、記錄借閱與歸還，並即時掌握可借數量及書籍狀態。
- 使用者角色：已進入管理控制台的管理員；一般讀者不直接操作本管理介面。
- 核心流程：新增書籍 → 在館藏列表確認書籍 → 輸入借閱人並借出 → 從借閱紀錄歸還 → 檢查數量與狀態恢復。
- 主要畫面區塊：TopBar、全域搜尋欄、借書／還書分頁卡、新增書籍表單、館藏列表、狀態訊息與 toast 通知。
- In-scope：新增書目及初始庫存、館藏列表、單本借出、單本歸還、可借數／總數更新、可借閱／已借出／未上架狀態、主要成功與失敗回饋。
- Out-of-scope：登入與角色管理、書目編輯或刪除、批次匯入、報表、通知寄送、完整逾期催收、超出本情境的複本增補流程。
- 前置條件與外部依賴：管理員已具備有效的管理權限；書籍與借閱資料須由應用程式的資料儲存層提供；認證、正式部署與資料庫選型交由 Archi／SD 定義。
- 名詞定義：書目是以 ISBN 或其他唯一識別值識別的書籍；複本是書目的庫存單位；可借數是尚未借出的複本數；借閱紀錄是一次借出與歸還的關聯資料。

## 2) Functional Requirements (FR)

### FR-001 建立書籍與初始館藏

- 使用者／觸發者：管理員在「新增書籍」表單送出資料。
- 前置條件：管理員已進入控制台；輸入資料符合欄位格式；初始庫存數量為正整數。
- 使用者輸入：書名、作者、ISBN、分類、數量及上架狀態。書名與作者來自 scenario；ISBN、分類與上架狀態來自 Figma UI，欄位必填性依 Q-001 定案。
- 業務行為：驗證欄位與唯一識別值；建立一筆書目，將總數與可借數設為初始數量；依上架狀態建立可借閱或未上架狀態。
- 成功結果：回傳成功業務碼 00000；館藏列表新增書目；畫面顯示成功訊息，並呈現正確的可借數／總數與狀態。
- 失敗結果：資料不合法、唯一識別值重複或儲存失敗時不得新增部分資料；回傳對應業務錯誤碼並在表單附近顯示可理解的錯誤回饋。

### FR-002 借出書籍

- 使用者／觸發者：管理員從借書分頁或館藏列表的「借出」動作發起借閱。
- 前置條件：書目存在、書籍已上架、可借數大於零，且借閱人識別值不為空白。
- 使用者輸入：借閱人姓名或讀者 ID、ISBN 或書目識別值；到期日為 Figma UI 顯示的可選欄位。
- 業務行為：確認書目與可借狀態；建立一筆借閱紀錄；可借數減少一；若借出後可借數為零則狀態改為已借出，仍有可借複本時維持可借閱。
- 成功結果：回傳成功業務碼 00000；館藏列表的可借數減一；借閱紀錄可被後續歸還流程識別；畫面顯示借出成功及必要的到期資訊。
- 失敗結果：書目不存在、無可借複本、未上架、借閱人無效或重複提交時，不建立借閱紀錄且不得使可借數變成負數；顯示錯誤訊息。

### FR-003 歸還書籍

- 使用者／觸發者：管理員從借閱紀錄或館藏列表的「歸還」動作發起歸還。
- 前置條件：可識別的書目與有效借閱紀錄存在，且該書目目前至少有一筆未歸還紀錄。
- 使用者輸入：ISBN 或書目識別值；讀者 ID 為 Figma 還書分頁的可選欄位；若同一書目有多筆借閱，需使用可唯一識別借閱紀錄的值。
- 業務行為：結束一筆借閱紀錄；可借數增加一；可借數等於總數時狀態改為可借閱，仍有未歸還複本時維持已借出；不得超過總數。
- 成功結果：回傳成功業務碼 00000；畫面顯示歸還成功；館藏列表的可借數增加一並反映新的狀態。
- 失敗結果：書目不存在、沒有未歸還紀錄、歸還識別值不明確或重複歸還時，不修改館藏數量與借閱狀態；顯示錯誤訊息。

### FR-004 顯示館藏與可操作狀態

- 使用者／觸發者：管理員開啟控制台、完成新增、借出或歸還後查看館藏列表。
- 前置條件：系統可讀取館藏資料；若尚無館藏，列表仍需提供空狀態。
- 使用者輸入：可透過館藏列表的借出／歸還動作操作；Figma TopBar 的搜尋欄是否執行篩選依 Q-006 定案。
- 業務行為：顯示書名、ISBN、作者、分類、狀態、可借數／總數及動作欄；依書目狀態停用不允許的動作；資料變更後重新呈現最新值。
- 成功結果：管理員可在清單找到指定書籍並判斷是否可借；空清單顯示「尚無館藏」及引導新增的訊息。
- 失敗結果：讀取失敗時顯示列表載入錯誤與重試可能性；不得以空清單誤導管理員資料不存在。

### FR-005 回饋交易結果與防止重複提交

- 使用者／觸發者：管理員送出新增、借出或歸還動作。
- 前置條件：表單已通過前端基本驗證，且後端仍會執行完整業務驗證。
- 使用者輸入：表單欄位與動作按鈕。
- 業務行為：送出期間提供處理中狀態；成功後更新列表與相關表單訊息；失敗後保留可修正的輸入，避免重複送出造成多筆交易。
- 成功結果：成功與失敗均以畫面內訊息及 toast 或等效通知回饋；回饋內容不得只依賴顏色。
- 失敗結果：網路或系統錯誤時顯示系統錯誤業務碼 B0000 的通用訊息；未確認結果時不得樂觀扣減或增加庫存。

### FR-UI-001 前端畫面對齊設計

- 前端需對齊 `docs/figma/library-mini-admin-console/README.md` 指向的 Figma Make 畫面與匯出元件：TopBar、借書／還書分頁、新增書籍表單、館藏列表與回饋訊息。
- 兩欄版面在寬螢幕呈現，窄螢幕可堆疊；欄位標籤、必填標示、按鈕文字、狀態 badge、空列表狀態與 disabled 條件需與設計語意一致。
- 借出動作在可借數為零或書籍未上架時 disabled；歸還動作在可借數等於總數時 disabled；disabled 不得只以視覺透明度表達，需有原生 disabled 或等效可存取狀態。
- 匯出原始碼目前沒有情境專用 `data-testid`。FE 需在實作前凍結穩定 locator 契約，建議使用 `library-topbar-search`、`library-borrow-tab`、`library-return-tab`、`library-add-book-form`、`library-book-title-input`、`library-book-isbn-input`、`library-book-author-input`、`library-book-quantity-input`、`library-add-book-submit`、`library-borrow-submit`、`library-return-submit`、`library-book-table`、`library-book-row` 搭配 row 的 `data-book-id`；後續 UI 變更必須維持既有 `data-testid`。
- Figma export 的作者欄位可選、scenario 描述輸入作者，ISBN／分類／上架狀態及全域搜尋的必要性則依 Q-001、Q-006 釐清；未定案前不得以視覺稿自行推導額外核心流程。

## 3) Non-Functional Requirements (NFR)

### NFR-001 一致性與庫存不變量

- 類型：一致性
- 需求：每筆借出／歸還需以一致的業務操作更新借閱紀錄、可借數與狀態；不可出現負數、超過總數或狀態與數量不一致。
- 驗證方式：以單複本、多複本、重複提交與併發請求測試資料庫或服務層結果。
- MVP 目標或限制：MVP 至少保證單一服務實例下的原子更新；跨服務鎖定與高併發策略由 Archi／SD 定義。

### NFR-002 可用性與無障礙

- 類型：可用性
- 需求：所有輸入有可見標籤與必填提示；鍵盤可完成分頁切換與表單送出；focus、disabled、錯誤與成功狀態可被非色彩方式辨識；表格在窄螢幕可水平捲動或使用等效呈現。
- 驗證方式：鍵盤操作檢查、語意 HTML／ARIA 檢查、桌面與窄螢幕瀏覽器檢查。
- MVP 目標或限制：沿用 Figma export 的簡潔卡片與表格視覺，不要求本情境新增複雜互動元件。

### NFR-003 操作回應時間

- 類型：效能
- 需求：在 MVP 預設資料量與正常網路條件下，新增、借出、歸還成功或失敗結果應於 2 秒內反映在畫面；處理期間按鈕不可重複提交。
- 驗證方式：Playwright 量測送出至結果訊息與列表更新的時間，並記錄測試資料量與環境。
- MVP 目標或限制：此數值為本地 MVP 驗收目標；正式容量與 SLA 由 Archi 定義。

### NFR-004 錯誤與可觀測性

- 類型：可觀測性
- 需求：每個 API 回應均包含業務錯誤碼；成功使用 00000，客戶端輸入或狀態錯誤使用 A0000，系統錯誤使用 B0000，第三方錯誤使用 C0000；HTTP status 不得取代業務碼。
- 驗證方式：逐一檢查成功、驗證失敗、業務衝突、系統例外的 response envelope 與前端映射；檢查交易失敗是否有可追蹤 log。
- MVP 目標或限制：本情境不依賴第三方服務，因此預期不觸發 C0000；細部錯誤子碼與 log 欄位由 SD 定稿。

### NFR-005 響應式與瀏覽器相容性

- 類型：相容性
- 需求：支援現代桌面瀏覽器與窄螢幕視窗；兩欄區塊需在窄螢幕可讀，館藏表格不得遮蔽主要資料與動作。
- 驗證方式：至少以 Chromium 桌面視窗及窄螢幕 viewport 執行 UI smoke 檢查。
- MVP 目標或限制：不要求舊版瀏覽器專屬 polyfill；具體瀏覽器矩陣由 FE／QA 依專案設定確認。

## 4) Acceptance Criteria (AC, Given/When/Then)

### AC-001 新增書籍成功

- Given 管理員已進入控制台並填入有效書名、作者、ISBN、分類、數量與上架狀態
- When 管理員送出新增書籍表單
- Then API 回傳業務碼 00000，館藏列表新增一列，總數與可借數等於輸入數量，且畫面顯示新增成功回饋

### AC-002 新增書籍失敗

- Given 管理員未填入任一最終定義的必填欄位，或輸入重複 ISBN／非正整數數量
- When 管理員送出新增書籍表單
- Then 系統回傳 A0000，列表與既有書目不變，表單顯示可修正的欄位或業務錯誤訊息

### AC-003 借出最後一本複本

- Given 館藏列表有一筆已上架且可借數為 1 的 Clean Code，管理員輸入借閱人 Samson 與該書 ISBN
- When 管理員執行確認借出
- Then API 回傳 00000，建立 Samson 的借閱紀錄，可借數由 1 變為 0，狀態變為已借出，且借出動作進入 disabled 狀態

### AC-004 借出仍有可借複本

- Given 書目總數為 2 且可借數為 2，管理員輸入有效借閱人與書目識別值
- When 管理員執行確認借出
- Then API 回傳 00000，可借數由 2 變為 1，狀態維持可借閱，且只新增一筆借閱紀錄

### AC-005 借出失敗不修改庫存

- Given 管理員選擇不存在、未上架或可借數為 0 的書目
- When 管理員送出借出操作
- Then 系統回傳 A0000，未新增借閱紀錄，館藏可借數與狀態不變，畫面顯示對應失敗原因

### AC-006 歸還最後一筆借閱

- Given Clean Code 有一筆 Samson 的未歸還借閱紀錄，且歸還前可借數為 0
- When 管理員從該筆借閱紀錄或還書流程執行確認歸還
- Then API 回傳 00000，該借閱紀錄標記為已歸還，可借數變為總數，狀態變為可借閱，且歸還動作進入 disabled 狀態

### AC-007 歸還失敗不修改庫存

- Given 管理員對不存在的書目或沒有未歸還紀錄的書目執行歸還
- When 系統處理歸還請求
- Then 系統回傳 A0000，館藏可借數、總數、狀態與既有借閱紀錄均不變，畫面顯示沒有借出記錄或找不到書籍

### AC-008 多複本歸還維持狀態

- Given 書目總數為 2、兩本皆曾借出，且已有一筆借閱紀錄先歸還
- When 管理員再確認另一筆歸還
- Then 每次請求只增加一個可借數與結束一筆借閱紀錄，第二次完成後可借數為 2 且狀態為可借閱

### AC-UI-001 前端畫面對齊驗收

- Given FE 依需求實作控制台並提供穩定 `data-testid` locator
- When QA 檢查指定 Figma 設計來源的 TopBar、借書／還書分頁、新增書籍表單、館藏列表、空狀態、錯誤回饋與 disabled 動作
- Then 畫面結構、文案語意、欄位與狀態呈現需與 Figma 設計來源 `docs/figma/library-mini-admin-console/README.md` 一致；任何差異均須附差異清單，且既有 `data-testid` 不得任意更名或移除

### AC-009 交易錯誤與系統錯誤回饋

- Given 管理員執行新增、借出或歸還，且輸入錯誤或服務發生未預期錯誤
- When API 回傳 A0000 或 B0000
- Then 前端保留可修正的輸入、不得更新未確認的庫存，並顯示與業務碼相符且不只依賴顏色的錯誤回饋

## 業務錯誤情境與錯誤碼需求

> 本文件依 AGENTS.md 採用全域業務碼分類。A0000、B0000、C0000 的細部子碼、response envelope 與 HTTP mapping 由 SD 於後續文件定稿；任何 HTTP status 不得單獨作為業務結果。

| 錯誤情境 | 建議業務碼 | 觸發條件 | 使用者可見訊息 | UI 處理 | 可重試 |
| --- | --- | --- | --- | --- | --- |
| 必填欄位缺漏或格式不合法 | A0000 | 書名、ISBN、數量或其他最終必填欄位無效 | 請修正標示欄位 | 保留輸入並定位錯誤欄位 | 否 |
| ISBN 或唯一識別值重複 | A0000 | 新增書目識別值已存在 | ISBN 已存在，無法重複新增 | 顯示欄位或表單錯誤，不新增列表列 | 否 |
| 書目不存在 | A0000 | 借出或歸還找不到識別值 | 找不到該書籍 | 維持原列表，允許修正後重試 | 是 |
| 無可借複本或書籍未上架 | A0000 | 可借數為零或狀態為未上架 | 該書籍目前無法借閱 | 借出動作 disabled 或顯示原因 | 否 |
| 沒有可歸還借閱紀錄 | A0000 | 可借數等於總數或 loan 已結束 | 該書籍沒有借出記錄 | 歸還動作 disabled 或顯示原因 | 否 |
| 併發更新造成版本衝突 | A0000 | 送出時資料已被其他交易更新 | 資料已更新，請重新載入後重試 | 重新讀取列表，不套用過期結果 | 是 |
| API 或資料儲存層未預期錯誤 | B0000 | 服務例外、逾時或資料持久化失敗 | 系統暫時無法完成操作 | 不更新未確認資料並提供重試 | 是 |
| 第三方依賴失敗 | C0000 | 若未來依賴外部服務且外部服務失敗 | 外部服務暫時無法使用 | 不更新未確認資料並依重試策略處理 | 是 |
